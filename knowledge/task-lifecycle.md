# Cycle d'une tâche

1. Le directeur du groupe assigne le travail.
2. L'agent analyse avec sa doctrine et les playbooks, même hors ligne.
3. Il remet un dossier : constat, recommandation, pièce prête (courriel, script, offre, note).
4. Niveau 1 : le dossier est terminé et visible du supérieur.
5. Niveau 2 : le supérieur approuve ou refuse. L'agent ne se valide pas.
6. Niveau 3 : le supérieur recommande, puis le CEO signe. Sans recommandation, la signature est refusée par le système.
7. La sécurité peut geler avant l'étape 5 ou 6.
8. L'exécution consigne le résultat dans le journal. Elle ne fait pas sortir un message, un appel ou un paiement de la machine.
9. Le rapport du chef de cabinet se recalcule sur cet état. Il ne copie pas une version périmée.

Une tâche sans supérieur est un défaut d'organisation. Le chef de cabinet doit la voir.
