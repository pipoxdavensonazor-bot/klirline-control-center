# Contexte produit Klirline

Procédure interne. Elle ne promet pas qu'un agent est exécutable.

## Entrées

- Identifiant du produit.
- Fiche `knowledge/products.md` et, si le dépôt est ouvert, les fichiers qui montrent la fonction.
- Offre déjà approuvée par le CEO, s'il y en a une.

## Sorties

- Une fiche avec quatre lignes séparées : produit accessible, fonctionnalité vérifiée, préparation commerciale, agent configuré, agent exécutable.
- Limitations et responsable.
- Sources citées par chemin ou URL.

## Données manquantes

Écrire « non précisé » pour le prix public, le dépôt de code, le responsable nommé et toute fonction absente de la fiche ou du code ouvert. Ne pas inventer de stack.

## Réussite

Chaque affirmation de fonction pointe vers `knowledge/products.md` ou un fichier du dépôt ouvert. Une préparation commerciale n'est pas marquée comme une fonction vérifiée. Un agent du roster n'est pas marqué exécutable tant que le moteur et le budget ne le sont pas.

Centia reste une ligne de services dont l'offre se complète quand le CEO la fixe. KlirLead n'a pas de panneau web retenu. KlirPromo n'est pas dans la fiche : ne pas lui créer de site.
