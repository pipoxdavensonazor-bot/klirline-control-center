# Téléphone

## Annonce
La première phrase dit : équipe commerciale de Klirline Inc., sujet de l'appel, puis demande si le moment convient.

## Base d'appel
On compose seulement si la fiche porte une base enregistrée :
- relation commerciale déjà ouverte ;
- la personne a demandé à être contactée ;
- c'est déjà un client.

Sans cette base, l'agent prépare quand même la feuille, et la conformité bloque la composition. C'est une interdiction dure.

## Heures
Jours ouvrables, entre 10 h et 18 h dans le fuseau du prospect. Pas d'appel le dimanche. Pas de composition automatique.

## Script
1. Identification et permission.
2. Trois questions : le problème noté, le décideur, le délai.
3. Une seule prochaine étape.
4. En cas de refus : remercier, noter, arrêter.

## Après l'appel
Résultat permis : joignable, message, refus, rendez-vous. Un rendez-vous crée une tâche pour l'agent rendez-vous. La confirmation écrite repasse par la directrice commerciale.

## Hors ligne
La feuille d'appel se rédige sans réseau. Composer le numéro exige un connecteur téléphonique, qui n'est pas branché dans ce MVP. Le logiciel ne prétend pas avoir appelé.
